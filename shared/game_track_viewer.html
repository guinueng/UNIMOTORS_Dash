서킷 도면 등록 · 이미지 / 지도 JSON

선택한 서킷과 코스 버전에만 적용됩니다. 다른 코스에는 자동 적용하지 않습니다. 수신기에서는 게임을 일시정지한 뒤 등록하세요.

지도 JSON을 등록하거나 PNG/JPEG 배경을 등록할 수 있습니다. 이미지는 오른쪽이 +X, 위쪽이 +Z인 게임 좌표 방향으로 준비하고, 이미지 전체의 좌표 범위를 입력하세요. 일반 지도 캡처를 보정 없이 넣으면 궤적과 맞지 않습니다.
